Installation Instructions:
Create Database:

Create a MySQL database named sales_erp

Import the database.sql file to create tables

Configure Database:

Update config.php with your database credentials

Set the correct APP_URL for your installation

Create Upload Directories:

Create an uploads folder in your project root

Ensure it has write permissions (755 or 777)
